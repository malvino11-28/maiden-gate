## Status: In Development

O **Maiden-Gate** está em fase inicial de desenvolvimento. O objetivo é criar uma ferramenta que elimine o excesso de papéis na mesa e centralize as informações.

### Roadmap:
- [ ] **Autenticação:** Acesso diferenciado para Mestre e Jogadores.
- [ ] **Módulo do Jogador:** Criação de ficha e controle de recursos (HP, itens, etc).
- [ ] **Módulo do Mestre:** 
    - [ ] Banco de dados de NPCs e Inimigos.
    - [ ] Gerenciador de Locais e Mapas (Referência visual).
    - [ ] Visualização rápida dos status dos jogadores.
- [ ] **Customização:** Opções para adaptar o sistema para outros cenários.
